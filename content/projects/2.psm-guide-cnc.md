# Viajar con un menor: guía oficial para solicitar el permiso

A production-grade government guide platform built for **Burocracia Cero (B0)** / **Consejo Nacional de Competitividad (CNC)** of the Dominican Republic. This guide provides citizens with a clear, accessible, SEO-optimized resource for understanding and requesting travel permits for minors — complementing the main PSM platform.

## Overview

### The Challenge

Citizens needed a clear, authoritative guide explaining the exit permit process for minors — separate from the transactional PSM platform. The challenge was building a content-driven site that maximizes **discoverability (SEO)**, **accessibility (WCAG 2.1 AA)**, and **performance** for users across all devices and connection speeds.

Key product capabilities:

- **Static-first architecture** — pre-rendered pages for instant load times and maximum SEO crawlability.
- **Structured content** — clear, step-by-step guidance with FAQ sections and regulatory references.
- **Accessibility-first design** — WCAG 2.1 AA compliance, semantic HTML, screen-reader optimized.
- **Performance optimization** — minimal JavaScript, optimized assets, and fast Core Web Vitals.
- **Bilingual support (ES/EN)** — serving both Spanish and English-speaking users.

## My Process

### My Role

I served as the **tech lead**, owning the **frontend architecture** and guiding development. My focus areas:

- **Architecture & strategy** — chose Astro for static-first delivery, optimizing for SEO and performance over interactive complexity.
- **Performance optimization** — ensured fast Core Web Vitals through minimal JS, optimized images, and efficient asset loading.
- **SEO & discoverability** — implemented structured data, meta tags, sitemap generation, and semantic markup for maximum search visibility.
- **Accessibility** — enforced WCAG 2.1 AA compliance across all components with semantic HTML and ARIA patterns.
- **Content pipeline** — designed the content structure for easy authoring and maintenance by non-technical stakeholders.

### Built With

- Semantic, accessible HTML (WCAG 2.1 AA)
- [Astro](https://astro.build/) — static-first framework for performance and SEO
- [TypeScript](https://www.typescriptlang.org/) (strict)
- [Python](https://www.python.org/) — backend/data processing scripts
- Mobile-first, content-driven workflow
- SEO-optimized: structured data, meta tags, sitemap
- Performance-focused: minimal JS, optimized assets, fast Core Web Vitals

### What I Learned

Building a government guide site reinforced the importance of **choosing the right tool for the job** — Astro's static-first approach was the perfect fit for a content-driven site where SEO and performance matter more than interactivity. I deepened my experience with **performance optimization strategies**, **SEO best practices for government content**, and building **accessible experiences** that serve all citizens regardless of device or ability.
