# Seafari

A Safari-style browser built on top of Mozilla Firefox, replicating the look and feel of Safari for Linux users. Seafari pulls daily updates from Mozilla source code, staying current with Firefox security patches while maintaining its distinctive Safari-inspired UI.

## Overview

### The Challenge

Seafari needed a reliable, automated changelog and release process. Each release required manually tracking commits, identifying contributors, writing changelogs, and preparing binaries — a tedious, error-prone workflow that slowed down the release cadence.

## My Contribution

### What I Worked On

As a **contributor**, I built an automated changelog and release preparation system:

- **Changelog automation script** — created a shell script using GitHub CLI (`gh`) that automatically reads commits between releases, categorizes changes, and generates structured changelogs.
- **Contributor recognition** — the script identifies all contributors involved in each release, giving proper credit to everyone who participated.
- **Release preparation** — automated the process of compiling changelogs and preparing the release section with final binaries, reducing manual effort and human error.

Working on Seafari's release automation taught me about **GitHub CLI capabilities** for automating repository workflows and the importance of **consistent, automated changelogs** for open-source project sustainability. I learned how shell scripting can orchestrate complex multi-step release processes.
