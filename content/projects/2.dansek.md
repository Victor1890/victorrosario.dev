# Dansek Group Landing Page

A marketing landing page for Dansek Group. The goal was a single, fast-loading page that presents the brand and its services clearly and reads well on any screen.

I focused on a clean, responsive layout with a mobile-first build, keeping the markup semantic and the styling lightweight so the page stays quick to load.

## Built With

- Semantic HTML and a mobile-first, responsive layout
- [Vue](https://vuejs.org/) and [Nuxt](https://nuxt.com/) for the page structure
- [Tailwind CSS](https://tailwindcss.com/) for styling
